이 인턴쉽은 Frontend, Backend 등 다양한 포지션을 경험해볼 수 도 있다. 이러한 경험을 위한 지식을 저장하는 곳을 만들려고 한다.  

첫 시작은 Server다.  

## Server란?

**서버**는 네트워크를 통해 다른 컴퓨터나 디바이스에 <U>서비스를 제공하는 컴퓨터 시스템</U>을 의미한다.  

## Server 역할

- **데이터 제공**: 클라이언트로부터 요청을 받아 데이터를 전송하거나, 데이터베이스에 접근하여 정보를 가져와 제공한다.  
- **파일 저장 및 관리**: 서버는 파일 시스템을 통해 데이터를 저장하고 관리하며, 클라이언트가 필요로 하는 파일을 제공한다.    
- **애플리케이션 실행**: 웹 서버, 데이터베이스 서버 등 여러 유형의 서버는 특정 애플리케이션을 실행하고 서비스를 제공한다.  

## Server 유형

- 웹 서버
	- 역할: HTTP 프로토콜을 사용하여 웹 페이지와 관련된 파일을 클라이언트에 전송하는 역할을 한다.  
	- 예시: Apache, Nginx 등

- 데이터베이스 서버:
	- 역할: 데이터베이스에 접근하여 데이터를 읽거나 쓰는 등의 작업을 수행하여 데이터 관리를 담당한다.  
	- 예시: MySQL, PostgreSQL, MongoDB 등  

- 파일 서버:
	- 역할: 파일을 저장하고 관리하며, 클라이언트에게 파일에 대한 접근 권한을 부여한다.  
	- 예시: FTP 서버, NAS 등  

- 메일 서버:
	- 역할: 전자 메일을 송수신하고 저장하는 서버로, 클라이언트에게 이메일 서비스를 제공한다.  
	- 예시: Microsoft Exchange, Postfix 등

- 애플리케이션 서버:
	- 역할: 특정 애플리케이션을 실행하고 관리하여 클라이언트에게 서비스를 제공한다.  
	- 예시: Java EE 서버, Microsoft IIS 등

- 클라우드 서버:
	- 역할: 클라우드 서버는 가상 서버로서 클라우드 컴퓨팅 환경에서 실행된다. 필요에 따라 유연하게 확장 가능하며, 가상 머신 인스턴스로 제공된다.  
	- 예시: Amazon EC2, Microsoft Azure Virtual Machines, Google Cloud Compute Engine 등  

- 암호화 서버:
	- 역할: 암호화 서버는 데이터를 암호화하거나 복호화하는 역할을 한다. 보안 강화를 위해 사용되며, 주로 보안 감시 및 통제에 사용된다.  
	- 예시: Hardware Security Module (HSM) 등  

- DNS 서버:
	- 역할: DNS 서버는 도메인 이름을 IP 주소로 변환하거나 IP 주소를 도메인 이름으로 변환하는 역할을 한다. 네트워크에서 사용자가 사람이 읽을 수 있는 도메인 이름으로 리소스를 찾을 수 있도록 도와준다.  
	- 예시: BIND, Microsoft DNS 등  

- 인증 서버:
	- 역할: 인증 서버는 사용자의 신원을 확인하고 인가를 관리하는 역할을 한다. 주로 사용자 로그인 및 권환 부여에 사용된다. 
	- 예시: OAuth 서버, OpenID Connect 등  

## Server 중요성과 활용

- 신뢰성과 가용성: 서버의 중요성은 신뢰성과 가용성에 기인한다. 안정적으로 운영되는 서버는 시스템의 안정성을 보장하고 중단 없이 서비스를 제공할 수 있다.  
- 스케일링과 성능 향상: 서버는 필요에 따라 확장이 가능하며, 로드 밸런싱 등을 통해 성능을 향상시킬 수 있다.
