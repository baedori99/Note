## 멀티 체인 연결을 통한 프롬프트 작성 및 긍/부정 분류

Template 작성
- `만족도`,`맛`,`서비스`,`가격` 카테고리로 나누어 긍/부정 분류하기
- `맛` 부분에서 긍/부정은 여러 음식으로 인해 다양하게 나올 수 있다.
- 맛 관련 키워드를 나누어 긍/부정을 확인하고 이를 분류하고 맛에 대한 긍정/부정 분류를 맛에서 긍정 개수와 부정 개수를 확인하여 제일 개수가 많은 것으로 분류한다.

내가 생각한 방식
```python
"만족도": "긍정/부정/-"
"맛": ""
"음식1": ""
"음식2": ""
"서비스": ""
"가격": ""
```

문제점
- `맛` 카테고리에 저장을 안시키고 따로 항목을 만들어서 저장을 시킨다.
	- -> 무분별한 항목들이 생겨 분석에 차질이 생길 수 있다.

연구원님의 아이디어
- `맛` 카테고리의 긍정, 부정으로 나누어 안에 문자열로 키워드를 받는다.
	- `"맛 긍정": []`
	- `"맛 부정": []`
```python
"만족도": "긍정/부정/-"
"맛 긍정": ["키워드" / "-"]
"맛 부정": ["키워드" / "-"]
"서비스": "긍정/부정/-"
"가격": "긍정/부정/-"
```

- 에러 발생
	- for문 돌리는 중간에 `맛 긍정`부분이 없어지고 `만족도` 다음 바로 `서비스`가 들어간 경우가 생김 이로 인해 `KeyError`가 뜸
- 해결 방법
	- 위의 코드`combined_result.get("카테고리", "-")`를 넣어 `default`값을 만들어 넣어줬다.

- `Taste Positive`와 `Taste Negative`의 열이 리스트 또는 `[-]/["-"]` 형식으로 되어 있다.
	- [[과제 공부용#문자열(str)속 표현식(expression)인식하기|ast라이브러리]]를 이용하여 `ast.literal_eval()`로 문자열로 바꾸어 준다.
	- `Taste Negative` 열에 리스트가 안사라져 정규 표현식을 이용했다.

```python
import ast

for i in range(len(review)):
    try:
        review.loc[i, "Taste Positive"] = ", ".join(ast.literal_eval(review["Taste Positive"][i]))
        review.loc[i, "Taste Negative"] = ", ".join(ast.literal_eval(review["Taste Negative"][i]))
    except (ValueError, SyntaxError) as e:
        continue
```

```python
review["Taste Negative"] = review["Taste Negative"].replace(r"[^가-힣a-zA-Z0-9-, ]","", regex = True)
```

	- 맛에 대한 평가가 없는데 "음식 없음"을 써두는 경우도 있다.
	- 특히, 부정쪽 평가가 있을 때 "음식 없음"을 써두는 빈도가 컸다.
- "음식 없음"과 "-"의 구분이 확실하다면 완성된다고 생각한다.

4번 템플릿

```python
prompt = """\
# INSTRUCTION
1. You are tasked with classifying the sentiment as positive or negative based on reactions to taste in the SENTENCE.
2. If there is a reaction to taste, categorize the name of the food that caused the reaction as either "Taste Positive" or "Taste Negative".
3. If there is no reaction to taste, output "-" for both "Taste Positive" and "Taste Negative".
4. If there is a reaction to taste but the name of the food is not mentioned, output "음식 없음" for both categories.
5. Differentiate between reactions to the taste of food and evaluations of the restaurant.
6. Be careful not to mistake the name of a restaurant for the name of a food.
7. Output the result in dictionary format.

    "Taste Positive" : ["Food Name/음식 없음/-"]
    "Taste Negative" : ["Food Name/음식 없음/-"]

# SENTENCE: {sentence}
"""
```

- "맛있다"라는 표현이 적힌 리뷰글을 분류할 때 음식 이름이 안적혀있는 경우
	- "음식 없음"이라고 분류가 되어야한다.
	- 하지만 "음식 없음"이라고 분류 되는 경우도 있지만 "-"로 분류되는 경우도 있어서 분류에 대한 기준이 모호해진다.

### `PydanticOutputParser()`를 이용한 템플릿 작성

[[LangChain#1. PydanticOutputParser|PydanticOutputParser 노트]]
연구원님이 알려주신 `Pydantic` 라이브러리를 이용해 분류 기준을 더 정확하게 하여 출력한다.

`PydanticOutputParser()`의 예제를 먼저 실습해보고 리뷰글 긍/부정에 대해 실습을 하도록 하겠다.

#### 1번 예제(MBTI 짝궁)

랜덤 MBTI 유형의 특징을 `list`형식으로 출력한다.

```python
import pandas as pd
import json
from typing import List
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.pydantic_v1 import BaseModel, Field
from langchain_core.output_parsers import PydanticOutputParser
from langchain_core.runnables import RunnableParallel, RunnablePassthrough
from dotenv import load_dotenv
import re

load_dotenv()
model = ChatOpenAI(model_name="gpt-3.5-turbo")

class Personality(BaseModel):
    category: str = Field(description="MBTI유형 이름")
    info: List[str] = Field(description="MBTI유형의 특징")
personality_query = "랜덤 MBTI 유형의 특징을 출력해주세요."
output_parser = PydanticOutputParser(pydantic_object=Personality)

prompt = PromptTemplate(
    template = "Answer the user query.\n{format_instructions}\n{query}\n",
    input_variables=["query"],
    partial_variables={"format_instructions": output_parser.get_format_instructions()},
)
chain = prompt | model | output_parser
chain.invoke({"query": personality_query})
```

#### 3번 예제(긍/부정 분류)

`Category`에 따라 `Sentence`를 긍/부정에 해당하는 키워드로 분류한다.  
- 이번 예제는 연구원님의 github를 보고  했다.
- [연구원님 Pydantic 프롬프트 시도2](https://github.com/narae3759/PPS/blob/main/projects/intern_project/05_Analyze.ipynb)  

```python
# Setting
from typing import Dict, List, Optional
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.pydantic_v1 import BaseModel, Field
from langchain_core.output_parsers import PydanticOutputParser

load_dotenv()
model = ChatOpenAI(model_name="gpt-3.5-turbo")
```

```python
class ActionModel(BaseModel):
    positive: List[str] = Field(description="긍정을 나타내는 키워드")
    negative: List[str] = Field(description="부정을 나타내는 키워드")

class ReviewModel(BaseModel):
    category: str = Field(description="CATEGORY 문자열")
    action: ActionModel

parser = PydanticOutputParser(pydantic_object = ReviewModel)

template = """\
# INSTRUCTION
- 당신은 SENTENCE에서 CATEGORY에 따라 긍/부정에 해당하는 키워드를 분류하는 역할입니다.
- 키워드는 긍/부정의 대상이며, 명사만 추출하세요.
- FORMAT에 맞춰 답변하세요.

# FORMAT: {format_instructions}
# CATEGORY: {category}
# SENTENCE: {sentence}
"""

category = "맛"
sentence = "스테이크는 오늘은 맛있어요 파크뷰는 대게 맛집 가격이 올라서 솔직히 155만 원 대비 가성비는 이 젠 별로 인 것 같아 요 발레할 경우에만 주차 편해요 비 오는 오늘 같은 경우 발레 안했음"
prompt = PromptTemplate.from_template(template)
prompt = prompt.partial(format_instructions = parser.get_format_instructions())
output_parser = PydanticOutputParser(pydantic_object=ReviewModel)
chain = prompt | model | output_parser
chain.invoke({"category": category, "sentence": sentence})
```

```python
# 출력값
# ReviewModel(category='맛', action=ActionModel(positive=['스테이크', '대게'], negative=['가성비']))
```

- `PydanticOutputParser()`을 사용한 이유
	- LLM이 키워드 또는 단어에 대한 분류 기준이 부족하여 이를 보충하기 위함이다.
- 출력값을 보면 `category=맛`이고 `positive`에는 긍정적이었던 "스테이크" 그리고 맛집이어서 긍정으로 분리된 "대게"가 나왔다
- 하지만 `negative`에는 `맛`카테고리와 무관한 "가성비" 단어가 나오게 되었다.

- `prompt = prompt.partial(format_instructions = parser.get_format_instructions())`을 통해 `FORMAT`부분을 먼저 부분 실행한 뒤 나머지 `prompt`을 실행하게 되었다.
- `chain.invoke()`로 출력을 할 때 `format`형식의 변수들을 전부 적어줘야 에러가 없다.
