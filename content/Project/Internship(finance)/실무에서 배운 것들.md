## 2024-08-07
금융쪽 프로젝트를 하며 처음으로 DB 설계를 하며 고려해야 했던 부분에 대해서 적겠다.  

📌회원가입일, 회원정보 수정일, 삭제 여부가 필요한 이유 
- 아이디 중복 검사를 할 때 삭제된 회원은 중복 검사에 다시 안넣는 걸로 할 수도 있고 삭제회원 제외하고 회원 목록을 볼 수 있기 때문이다.  

📌로그인 기록등은 관리자 어드민에 의해 결정이 된다. 
- 필요할수도 있고 없을 수도 있고 

📌팀원분이 회원정보 테이블을 만드실 때 고려하신 부분
- 회원정보 테이블을 만들 때
	- 회원 정보 등록할 때 필요한 속성
	- 회원 정보 수정할 때 필요한 속성
- 회원 정보에 대한 모든 속성을 기재한다고 생각하면 편할거 같다.   
	- 팀원분-> 회원정보 등록할 때 넣는 정보들은 값 저장이 필요하고 수정할 때 수정하는 정보들도 있어야 수정하니까 필요하다.  
	- -> 관리자가 회원들 관리(조회, 삭제)등을 한다고 했을 떄 필요한 값은 원래 어드민 보고 추가한다.  

📌`datatype`을 정할 때 예/아니오 등의 선택형 답변에는 `CHAR(1)`을 대부분 쓰신다.  

📌또한 Y/N과 같은 경우엔 `Default`값을 지정하여 기본 선택을 지정해놓는다.  

📌이미지파일등에 대한 정보를 따로 저장을 한다.  
- 이미지 저장경로, 사이즈, 등록 날짜등을 저장한다.
