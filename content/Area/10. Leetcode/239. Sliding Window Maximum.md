# 239. Sliding Window Maximum

## 1. Description
- You are given an array of integers `nums`, there is a sliding window of size `k` which is moving from the very left of the array to the very right. You can only see the `k` numbers in the window. Each time the sliding window moves right by one position.

- Return _the max sliding window_.

## 2. Example
>[!example] Example 1
>**Input:** nums = `[1,3,-1,-3,5,3,6,7]`, k = 3
**Output:** `[3,3,5,5,6,7]`
**Explanation:** 
Window position                Max
>---------------               -----
>"`[1  3  -1]`-3  5  3  6  7"         **3**
> "1 `[3  -1  -3]` 5  3  6  7"         **3**
> "1  3 `[-1  -3  5]` 3  6  7"        **5**
> "1  3  -1 `[-3  5  3]` 6  7"         **5**
> "1  3  -1  -3 `[5  3  6]` 7"        **6**
> "1  3  -1  -3  5 `[3  6  7]`"       **7**

>[!example] Example 2
>**Input:** nums = `[1]`, k = 1
>**Output:** `[1]`


## 3. Solution
- Runtime: 179
- Time Complexity: `O(N)`
- 설명
	- `deque`를 만든다.
		- 📌`deque`를 사용하여 불필요한 요소들을 제거하고 유효한 최대값만 남겨 시간 복잡도를 줄인다.
		- 📌`deque`에 인덱스를 저장한 이유
			- `window` 범위 관리를 하기 위함이다.
			- `nums[q[0]]`(윈도우에서 가장 큰 값의 인덱스를 의미)을 통해 최대값을 빠르게 가져오기 위함이다.
	- `r`이 `len(nums)`까지 도달할 때까지 반복문을 실행한다.
	- 현재 요소보다 작은 값들은 덱에서 제거한다.
		- `q`가 비어있지 않고 `nums[q[-1]] < nums[r]`일 때 
		- `q[-1]`은 현재 덱에서 가장 최근에 추가된 인덱스이다.
		- 만약 현재 숫자(`nums[r]`)가 덱의 마지막 숫자(`nums[q[-1]]`)보다 크다면
			- 덱의 마지막 요소를 제거한다.
```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        result = []
        left = right = 0
        q = deque()

        while right < len(nums):
            # print("deque = ", q)
            # print("result = ", result)
            while q and nums[q[-1]] < nums[right]:
                q.pop()
            q.append(right)

            if left > q[0]:
                q.popleft()
            
            if (right + 1) >= k:
                result.append(nums[q[0]])
                left += 1
            right += 1
        return result
```
