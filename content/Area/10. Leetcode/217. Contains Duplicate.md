# 217. Contains Duplicate

## 1. Description
- Given an integer array `nums`, return `true` if any value appears **at least twice** in the array, and return `false` if every element is distinct.

## 2. Example
>[!example] Example 1
>**Input:** nums = [1,2,3,1]
>**Output:** true
>**Explanation:** The element 1 occurs at the indices 0 and 3.

>[!example] Example 2
>**Input:** nums = [1,2,3,4]
>**Output:** false
>**Explanation:** All elements are distinct.

## 3. Solution
1. 첫번째 풀이
	- Runtime: 49ms
	- 설명
		- 이 방법은 내 친구(Seong)가 생각한 방법이다.
		- List를 정렬을 한다.
		- List의 첫번째 index를 i로 칭하고 i와 i+1번째 List value를 비교한다.
		- 이를 `range(len(list)-1)`만큼 `for`문을 돌린다.
		- i와 i+1번째 List value가 같다면 `return True`, 다르면 `return False`를 나타낸다.
```python
class Solution:
    def hasDuplicate(self, nums: List[int]) -> bool:
        new = sorted(nums)
        #nums.sort()
        i = 0
        
        for num in range(len(new)-1):
            if new[i] == new[i+1]:
                return True
            else: 
                i = i+1
        return False
```

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        s = set()
        for n in nums:
            if n in s:
                return True
            else:
                s.add(n)
        return False
```
