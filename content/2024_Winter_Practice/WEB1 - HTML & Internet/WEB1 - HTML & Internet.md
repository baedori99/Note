## HTML
- HyperText Markup Language
### Public Domain
- 인간의 언어들이 저작권이 없는 Public Domain이다.
- WEB은 어떠한 저작권도 존재하지 않는 완전한 자유를 의미하는 Public Domain이다.

### HTML코딩과 실습환경 준비
- 준비물
	- 웹브라우저
	- 코드 편집기
- HTML의 확장자명은 `html`이다.

### 기본 문법 태그
- 태그
	- 모습을 설명한다.
	- 예시
		- `<strong></strong>`은 안의 단어 또는 문장을 중요하니까 진하게 표시해야 된다라는 것을 설명한다.
#### strong
- `strong`은 문장을 강조하기 위해 진하게 표시하게 해주는 태그이다.

```html
Markup Language (HTML) is the standard markup
language for <strong>creating web pages</strong> and web applications.
```

>[!example] 실행 결과
>![](https://imgur.com/3pC3btL.png)

#### underline `u`
- `u`는 밑줄을 긋게 하는 태그이다.
```html
Hypertext Markup Language (HTML) is the standard markup
language for <strong>creating <u>web</u> pages</strong> and web applications.
```
